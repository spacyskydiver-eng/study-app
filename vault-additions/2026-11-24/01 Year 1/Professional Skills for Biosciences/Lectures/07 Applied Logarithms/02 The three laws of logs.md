# The three laws of logs

> [!path] [[Professional Skills for Biosciences]] › [[Applied Logarithms (Maths 5)]]

*Source: Mathematical Concepts: Applied Logarithms, Dr Beth Williams (PowerPoint), slides 10-14*

| Law | Examples |
| --- | --- |
| **log A + log B = log(AB)** | log 9 + log 3 = log 27; log 3x² + log 2x = log 6x³ |
| **log A − log B = log(A/B)** | log 9 − log 3 = log 3; log 5x² − log x = log 5x |
| **n log A = log Aⁿ** | 3 log 2 = log 8; ½ log 16 = log 4; −log 4 = log 0.25 |

## Worked
- log 1 − log 100 = log(1/100) = log 10⁻² = **−2**
- 3 log x + log y − 2 log z = log x³ + log y − log z² = **log(x³y / z²)**
- log 4x + log x² − log 2x = log(4x³ / 2x) = **log 2x²**
