# Common and natural logs

> [!path] [[Professional Skills for Biosciences]] › [[Applied Logarithms (Maths 5)]]

*Source: Mathematical Concepts: Applied Logarithms, Dr Beth Williams (PowerPoint), slides 15-16, 24*

- **Common log**: base 10; if no base is shown, it is base 10 (log x = log₁₀ x)
- **Natural log**: base **e ≈ 2.71828** (Euler's number), written **ln**: log_e X = ln X
- ln A = x ⇔ **eˣ = A**
- Almost all biological log calculations use **natural logs**; the main exception is **pH** (base 10)

## Questions
> [!question]- Which log base is used for pH, and which for growth and decay?
> Base 10 for pH; natural logs (base e) for growth and decay.
