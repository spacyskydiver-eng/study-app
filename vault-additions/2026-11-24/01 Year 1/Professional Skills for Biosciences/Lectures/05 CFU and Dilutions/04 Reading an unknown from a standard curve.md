# Reading an unknown from a standard curve

> [!path] [[Professional Skills for Biosciences]] › [[CFU and Dilutions (Maths 3)]]

*Source: Mathematical Concepts: CFU and Dilutions (PowerPoint, Colony Forming Units), slides 16-19*

| Cyt c (µg mL⁻¹) | Absorbance |
| --- | --- |
| 400 | 1.500 |
| 200 | 1.250 |
| 100 | 0.843 |
| 50 | 0.400 |
| 20 | 0.165 |
| 10 | 0.082 |
| 5 | 0.040 |
| unknown | 0.625 |

- The curve flattens at 200 and 400 µg mL⁻¹ (saturation), so only the **linear part** (5 to 100) is fitted
- Line: **y = 0.0084x − 0.0057**, R² = 0.9992 → Abs = 0.0084(Conc) − 0.0057
- Rearrange: Conc = (Abs + 0.0057) / 0.0084 = (0.625 + 0.0057) / 0.0084 = **75.1 µg mL⁻¹**

## Questions
> [!question]- Abs = 0.0084(Conc) − 0.0057. What concentration gives A = 0.625?
> (0.625 + 0.0057)/0.0084 = 75.1 µg mL⁻¹.
