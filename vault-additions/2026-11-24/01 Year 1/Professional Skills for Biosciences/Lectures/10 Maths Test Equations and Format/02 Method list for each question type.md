# Method list for each question type

> [!path] [[Professional Skills for Biosciences]] › [[Maths Test - Equations and Format]]

*Source: Useful Equations sheet and Assessment Brief Quizzes (Blackboard, Maths for Bioscience), all maths lectures*

## Unit conversion
1. Write the value in base units with the prefix as a power (5 nL = 5 × 10⁻⁹ L)
2. Divide by the new prefix (÷ 10⁻³ for mL) → 5 × 10⁻⁶ mL
3. Squared or cubed units: square or cube the conversion (1 m² = 10⁶ mm²)

## Scale bar / magnification
1. Convert both lengths to the same unit
2. actual = image / magnification; magnification = image / actual

## CFU
1. Choose the plate with 30 to 300 colonies
2. colonies × dilution factor (positive power)
3. ÷ volume plated in **mL**
4. Per gram: ÷ grams of sample in the suspension

## Moles and molarity
1. Convert mass to g and volume to L
2. moles = mass / Mr; molarity = moles / volume
3. Dilutions: V₁ = M₂V₂ / M₁, same units both sides

## pH and buffers
1. pH = −log[H⁺]; [H⁺] = 10⁻ᵖᴴ
2. Buffer: work out [A⁻] and [HA] after any mixing, then pH = pKa + log([A⁻]/[HA])

## Growth
1. k = ln(N/N₀) / t; N = N₀eᵏᵗ; t½ = ln 0.5 / k

## Straight lines
1. m = (y₂ − y₁)/(x₂ − x₁); c = y − mx
2. Perpendicular m = −1/m; parallel same m

## Quadratics
1. Identify a, b, c (watch signs)
2. Roots: x = (−b ± √(b² − 4ac)) / 2a; turning point at x = −b/2a
