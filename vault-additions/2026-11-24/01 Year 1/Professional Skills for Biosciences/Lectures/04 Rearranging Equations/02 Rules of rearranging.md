# Rules of rearranging

> [!path] [[Professional Skills for Biosciences]] › [[Rearranging Equations (Maths 1)]]

*Source: Mathematical Concepts: Rearranging Equations, Dr Beth Williams (PowerPoint) and Maths Basic Rules helpsheet, slides 7-11*

- **Rearranging** = changing the subject of the equation, so an unknown can be found from known values (or to simplify)
- **Golden rule**: whatever you do to one side, do to the other
- Use **inverse operations**: + ↔ −, × ↔ ÷, x² ↔ ±√x
- Undo in the **reverse order of operations**: deal with + and − first, then × and ÷, then powers

## Examples
- x + 4 = y → **x = y − 4**
- z = 5y + x/4 → z − 5y = x/4 → **x = 4z − 20y**
- v − u = 2 → −u = 2 − v → **u = v − 2** (if the subject ends up negative, multiply through by −1)

## Lecture practice (worked)
| Make x the subject | Answer |
| --- | --- |
| a + 3x = y + x | 2x = y − a → x = (y − a)/2 |
| ax − y + z = b | x = (b + y − z)/a |
| 2w = 3x | x = 2w/3 |
| y = 7 − 2x | x = (7 − y)/2 |
| 2(x + a) = y | x = y/2 − a |
