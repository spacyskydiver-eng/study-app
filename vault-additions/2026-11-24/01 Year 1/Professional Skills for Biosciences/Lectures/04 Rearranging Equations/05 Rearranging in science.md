# Rearranging in science

> [!path] [[Professional Skills for Biosciences]] › [[Rearranging Equations (Maths 1)]]

*Source: Mathematical Concepts: Rearranging Equations, Dr Beth Williams (PowerPoint) and Maths Basic Rules helpsheet, slides 19-20*

- Units come from the equation: speed = distance / time → **m s⁻¹**; molar mass = mass / moles → **g mol⁻¹**
- Used throughout: y = mx + c (graphs), n = m/M and c = n/V (moles and molarity), C₁V₁ = C₂V₂ (dilutions)

| Starting formula | Rearranged |
| --- | --- |
| n = m / M | M = m / n; m = n × M |
| c = m / (M × V) | V = m / (M × c) |
| C₁V₁ = C₂V₂ | V₁ = C₂V₂ / C₁ |
| °C = (°F − 32) × 5/9 | °F = (9/5) × °C + 32, so 25 °C = 77 °F |
| A = ½bh | h = 2A / b |
| C = 2πr | r = C / 2π |

## Questions
> [!question]- Rearrange C₁V₁ = C₂V₂ for V₁.
> V₁ = C₂V₂ / C₁.

> [!question]- What is 25 °C in °F?
> (9/5 × 25) + 32 = 77 °F.
