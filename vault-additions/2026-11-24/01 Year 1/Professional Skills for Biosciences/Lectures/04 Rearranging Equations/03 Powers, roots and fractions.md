# Powers, roots and fractions

> [!path] [[Professional Skills for Biosciences]] › [[Rearranging Equations (Maths 1)]]

*Source: Mathematical Concepts: Rearranging Equations, Dr Beth Williams (PowerPoint) and Maths Basic Rules helpsheet, slides 12-15*

## Indices
- Square and square root are inverses; a square root has **two** answers (±)
- √x − 3 = y → √x = y + 3 → **x = (y + 3)²** = y² + 6y + 9
- ax² + b = c → x² = (c − b)/a → **x = ±√((c − b)/a)**

## Fractions
- Clear a fraction by multiplying both sides by its denominator (inverse of dividing)
- 6 + 3y = 1/(3t) + 2 → 4 + 3y = 1/(3t) → 3t(4 + 3y) = 1 → **t = 1 / (3(4 + 3y))**

## Lecture practice (worked)
| Make x the subject | Answer |
| --- | --- |
| x/a = (y + z)/b | x = a(y + z)/b |
| √x + 4y = c | x = (c − 4y)² |
| x² − y² = a² | x = ±√(a² + y²) |
