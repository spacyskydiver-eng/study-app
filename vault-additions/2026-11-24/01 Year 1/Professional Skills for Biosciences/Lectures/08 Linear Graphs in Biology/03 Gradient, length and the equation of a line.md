# Gradient, length and the equation of a line

> [!path] [[Professional Skills for Biosciences]] › [[Linear Graphs in Biology (Maths 6)]]

*Source: Mathematical Concepts: Linear Graphs in Biology, Dr Beth Williams (PowerPoint), slides 17-21*

- **Gradient** = Δy/Δx = (y₂ − y₁)/(x₂ − x₁): how fast y changes with x
- **Length** = √((x₂ − x₁)² + (y₂ − y₁)²) (Pythagoras)
- (1, 2) and (3, 4): gradient 2/2 = **1**; length √(2² + 2²) = **2.83**

## Equation from two points
1. Find m from the two points
2. Substitute one point into y = mx + c and solve for c
- (1, −2) and (−3, 6): m = (6 − (−2))/(−3 − 1) = 8/−4 = **−2**; −2 = −2(1) + c → c = 0 → **y = −2x**
- A(3, 6), B(0.2, 4): m = 2/2.8 = **0.714**; c = 6 − 0.714 × 3 = 3.86 → **y = 0.714x + 3.86**

## Gradient and intercept from a rearranged line
- 3x − 4y + 4 = 0 → 4y = 3x + 4 → y = 0.75x + 1: **m = 0.75, c = 1**
- 2x − 3y + 6 = 0 → y = (2/3)x + 2: **m = 2/3, c = 2**
