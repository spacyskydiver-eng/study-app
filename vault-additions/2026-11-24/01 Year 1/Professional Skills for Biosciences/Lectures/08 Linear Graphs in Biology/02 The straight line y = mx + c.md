# The straight line y = mx + c

> [!path] [[Professional Skills for Biosciences]] › [[Linear Graphs in Biology (Maths 6)]]

*Source: Mathematical Concepts: Linear Graphs in Biology, Dr Beth Williams (PowerPoint), slides 7-16*

- **y = mx + c**: y dependent, x independent, **m gradient (slope)**, **c y-intercept** (y when x = 0)
- Linear: y changes by a **steady amount** for each step in x
- m > 0: line slopes up; m < 0: line slopes down

## DNA absorbance at 260 nm
| DNA (µg mL⁻¹) | A₂₆₀ |
| --- | --- |
| 2 | 0.06 |
| 4 | 0.155 |
| 8 | 0.25 |
| 12 | 0.375 |
| 18 | 0.51 |
| 22 | 0.66 |
| 30 | 0.825 |
- Best-fit line: **A = 0.0271(Conc) + 0.0328**, **R² = 0.9941** (R² = how close the points are to the line)
- Unknown concentration: Conc = (A − 0.0328) / 0.0271

## Questions
> [!question]- Using A = 0.0271(Conc) + 0.0328, what concentration gives A = 0.5?
> (0.5 − 0.0328)/0.0271 = 17.2 µg mL⁻¹.
