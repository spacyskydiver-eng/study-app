# Exponential graphs and linearising them

> [!path] [[Professional Skills for Biosciences]] › [[Non-linear Graphs in Biology (Maths 7)]]

*Source: Mathematical Concepts: Non-linear Graphs in Biology (PowerPoint), slides 2-7*

- Many biological relationships are non-linear; we **transform** them (e.g. by logging) into **y = mx + c** so the intercepts can be read accurately and are biologically relevant
- **Exponential**: y = aˣ (a constant), e.g. bacteria or yeast dividing at regular intervals
- y = 2ˣ: 1, 2, 4, 8, 16, 32 for x = 0 to 5; **when x = 0, y = 1** for any a (a⁰ = 1)

## Linearising N = N₀eᵏᵗ
1. N/N₀ = eᵏᵗ
2. ln(N/N₀) = kt
3. Second log law: ln N − ln N₀ = kt
4. **ln N = kt + ln N₀** (y = mx + c)
- Plot **ln N against t**: straight line, **gradient = k**, **y-intercept = ln N₀**

## Questions
> [!question]- Linearise N = N₀eᵏᵗ. What do you plot and what is the gradient?
