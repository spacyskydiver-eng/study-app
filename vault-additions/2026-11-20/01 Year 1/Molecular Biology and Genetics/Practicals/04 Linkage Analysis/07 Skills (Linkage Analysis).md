# Skills

> [!path] [[Molecular Biology and Genetics]] › [[Linkage Analysis practical]]

*Source: Practical Manual 2 4018A (Genetics and transformation), page 1*

## Skills learnt
- Setting up **PCR** with a master mix, primers and template DNA
- Running and reading an **agarose gel** against a size ladder
- Working out a **genotype** from band patterns
- Calculating a **recombination frequency** and a **map distance** in centiMorgans

## Common mistakes
- Calling type **ii** recombinant because it has "a and b" alleles: it isn't, Parent 1 already had M1b with M2b
- Forgetting that the **a** allele is the shorter product in both markers
- Giving the map distance as 0.15 instead of **15 cM**
