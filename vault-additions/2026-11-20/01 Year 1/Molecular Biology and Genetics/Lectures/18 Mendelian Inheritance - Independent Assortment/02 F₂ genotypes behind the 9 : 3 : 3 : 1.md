# F₂ genotypes behind the 9 : 3 : 3 : 1

> [!path] [[Molecular Biology and Genetics]] › [[Mendelian Inheritance - Independent Assortment (Lecture 18)]]

*Source: Lecture 18: Mendelian inheritance - independent assortment (PowerPoint), slides 9-14*

| Genotype | Fraction | Phenotype | Class total |
| --- | --- | --- | --- |
| LeLe II | 1/16 | tall yellow | |
| LeLe Ii | 2/16 | tall yellow | |
| Lele II | 2/16 | tall yellow | |
| Lele Ii | 4/16 | tall yellow | **9/16** |
| LeLe ii | 1/16 | tall green | |
| Lele ii | 2/16 | tall green | **3/16** |
| lele II | 1/16 | dwarf yellow | |
| lele Ii | 2/16 | dwarf yellow | **3/16** |
| lele ii | 1/16 | dwarf green | **1/16** |

- **9 genotypes**, **4 phenotypes**
- Each class needs at least one dominant allele for each dominant trait it shows: tall green = **Le_ ii** (LeLe ii or Lele ii)

## Questions
> [!question]- Give the possible genotypes of a tall green F₂ plant.
> LeLe ii or Lele ii.

> [!question]- What fraction of the F₂ is Lele Ii?
> 4/16 = ¼.
